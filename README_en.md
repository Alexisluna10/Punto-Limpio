# Punto Limpio - Laundry Management System 

This repository contains the source code for **Punto Limpio**, a web platform developed as a custom software solution to manage the operations of a real laundry business. 

The system was designed and built collaboratively by a 3-person development team, focusing on scalability, data security, and the automation of internal processes.

## Live Demo
You can test the platform and see the architecture in action at the following production deployment link:
**[View Punto Limpio Demo on Render](https://punto-limpio.onrender.com)**

*(Note: The demo database is periodically reset. Test credentials are included within the platform, or you can register a new account).*

## 🛠️ Tech Stack
The project's architecture is built with the following technologies:
* **Backend:** Python / Django
* **Database:** PostgreSQL (Hosted on Supabase with Transaction Pooling)
* **Deployment & CI/CD:** Render (Web Service) with automation and idempotency scripts (`build.sh`).
* **Email Handling:** Integration with Brevo API.
